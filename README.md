# Abraham Ortiz - Personal Portfolio

A modern, responsive personal portfolio website showcasing my experience, projects, and technical skills as a Full-Stack Developer.

## 🌟 About

This is my personal portfolio website where I present my professional journey, highlight key projects, and demonstrate my technical expertise.


## 🛠️ Tech Stack

- **Astro** - Modern static site generator
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **Custom Components** - Reusable Astro components


## 🚀 Getting Started

> Node.js version used: **22.5.1**

### Backend Setup
```bash
npm install  
npm run dev
```

## 🚧 Build & Deploy

### Backend
```bash
npm run build
```
